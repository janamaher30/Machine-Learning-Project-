# Machine Learning Project

A Machine Learning course project covering three main tasks: Numerical Regression, Image Classification, and Text Classification.

## Project Overview

The project aims to apply different Machine Learning algorithms to real-world-style datasets, perform data preprocessing, train and evaluate models, and compare their performance.

## Project Parts

### Part A: Numerical Regression

**Dataset:** [Student Performance](https://www.kaggle.com/datasets/nikhil7280/student-performance-multiple-linear-regression)

**Target Variable:** Performance Index

**Models:**
- Linear Regression
- K-Nearest Neighbors (KNN) Regressor

[Open Part A Notebook](Part_A_Regression.ipynb)

### Part B: Image Classification

**Dataset:** [Flowers Recognition](https://www.kaggle.com/datasets/alxmamaev/flowers-recognition)

**Classes:**
- Daisy
- Dandelion
- Rose
- Sunflower
- Tulip

**Models:**
- Logistic Regression
- K-Nearest Neighbors (KNN) Classifier
- K-Means Clustering

[Open Part B Notebook](Part_B_Image_Classification.ipynb)

### Part C: Text Classification

**Dataset:** [IMDb Movie Reviews](https://zenodo.org/records/7929635)

**Classes:**
- Positive
- Negative

**Models:**
- Logistic Regression
- Linear Support Vector Machine (SVM)

**Bonus:**
- Voting Classifier (Ensemble Learning)

[Open Part C Notebook](Part_C_Text_Classification.ipynb)

## How to Use

1. Clone or download this repository.
2. Open the required Jupyter Notebook using Google Colab.
3. Connect your Google Drive.
4. Make sure the corresponding dataset is available in your Google Drive.
5. Run the notebook cells and continue working on your assigned part.
